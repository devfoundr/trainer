# Макет сайта персонального тренера

Одностраничный макет сайта для персонального тренера. Один файл `index.html`, без сборки и зависимостей.

**Демо:** https://devfoundr.github.io/trainer/

## Что внутри

- Первый экран с позиционированием и призывом записаться
- Блоки об услугах, подходе к работе и результатах
- Адаптивная вёрстка под телефон
- Форма записи

## Зачем

Макет для показа заказчику до начала разработки: клиент видит структуру и стиль на реальной странице, а не на картинке, и правки собираются до того, как сайт начали делать всерьёз.

Из той же серии — рабочие приложения для тренировок: [Подход](https://github.com/devfoundr/podhod) и [конструктор программ для тренера](https://github.com/devfoundr/podhod-coach).
